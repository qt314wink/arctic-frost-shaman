# ❅️ Arctic Frost Shaman

> *Ice-crystal shamanic generative art — tundra spirits, frost geometry, and glacial kintsugi.*

An interactive single-page canvas experience in the same series as `volcanic-obsidian-ember`, `desert-mirage-nomad`, and `luminous-lunarpunk` — each a distinct elemental aesthetic world built with raw Canvas API and GSAP.

This repo belongs to the **Elemental Mythpunk Series** — a collection of generative web art pieces exploring elemental forces through kintsugi repair mythology, tactile material aesthetics, and ambient interactive audio.
